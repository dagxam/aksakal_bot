# Аксакал — Telegram-бот для живой группы

Аксакал участвует в беседе как живой собеседник: отвечает на сообщения через Telegram Reply, поэтому имя пользователя в текст ответа не добавляется.

## Уже работает

- хранение последних сообщений группы в SQLite;
- контекстные подколы через AI;
- AUTO-режим: сам выбирает Нормальный, Злой или Супер злой по текущему разговору;
- реакция на стикеры;
- получение Telegram reactions;
- режим «молчун»: после долгой тишины выбирает участника и пытается оживить чат;
- антиспам и cooldown, чтобы не долбить одного человека;
- добровольный `/profile male|female|neutral`, чтобы менять стиль шуток без угадывания пола по имени;
- `/roast` ответом на конкретное сообщение;
- AI-only ответы без готовых фраз: при сбое одной модели бот пробует следующую.

## Важное ограничение Telegram

Обычный Telegram Bot API не даёт боту список людей, которые прямо сейчас online. Поэтому «сидит в сети, но молчит» определяется косвенно: по недавним сообщениям, реакциям и стикерам.

Чтобы бот видел обычные сообщения группы, отключите Privacy Mode у BotFather (`/setprivacy`) либо назначьте бота администратором. Для событий `message_reaction` бот должен быть администратором; код уже явно запрашивает этот тип update.

## Быстрый запуск в Telegram-группе

1. В **@BotFather** откройте `/mybots` → выберите Аксакала.
2. В **Bot Settings → Group Privacy** выключите Privacy Mode (`Disable`). Иначе бот по умолчанию не видит обычный разговор группы.
3. Через **Edit Bot → Edit Botpic** (или команду `/setuserpic`) установите аватар Аксакала.
4. Добавьте бота в нужную группу и назначьте **администратором**. Это особенно важно для получения событий реакций.
5. На сервере заполните локальный `.env`: `TELEGRAM_BOT_TOKEN` и `GROQ_API_KEY`. `MISTRAL_API_KEY` можно добавить как независимый резерв.
6. Запустите `python bot.py`. Процесс должен постоянно работать — GitHub сам по себе бота не запускает.
7. В группе отправьте `/test`. Ответ **«Аксакал жив…»** означает, что Telegram → сервер → бот работают.
8. Затем отправьте `/status` и несколько обычных сообщений. Самостоятельные шутки бот пишет не на каждое сообщение — это намеренно, чтобы не спамить.

После запуска код сам:
- удаляет старый webhook, чтобы long polling мог работать;
- регистрирует меню Telegram-команд;
- задаёт имя и описание бота.

### Если `/test` не отвечает

Смотрите консоль процесса `python bot.py`. При правильном токене в начале должно быть:
`Аксакал запущен: @username_бота`.

Если этой строки нет — бот фактически не запущен либо неверен токен.

## Запуск

Нужен Python 3.11+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните локальный `.env`:

```env
TELEGRAM_BOT_TOKEN=
GROQ_API_KEY=
GROQ_MODELS=openai/gpt-oss-120b,qwen/qwen3.8-27b,openai/gpt-oss-20b

# Необязательный независимый резерв
MISTRAL_API_KEY=
MISTRAL_MODEL=mistral-small-latest

DATABASE_PATH=aksakal.db
DEFAULT_ROAST_LEVEL=3
MIN_BOT_INTERVAL_MINUTES=10
DEFAULT_RESPONSE_DELAY_SECONDS=20
SILENCE_TRIGGER_MINUTES=180
CONTEXT_MESSAGE_LIMIT=40
AI_ENABLED=true
AUTO_REPLY_EVERY_MESSAGE=false
```

**Никогда не коммитьте реальные `TELEGRAM_BOT_TOKEN`, `GROQ_API_KEY` или `MISTRAL_API_KEY` в публичный GitHub.**

Запуск:

```bash
python bot.py
```

## Команды

В группах Telegram-командное меню специально скрыто, чтобы служебные команды не засоряли чат. Команды при этом работают.

- `/settings` — открыть настройки Аксакала;
- `/status` — текущее состояние;
- `/games` — открыть игровой центр;
- `/crocodile` — «Крокодил»; `hint`, `skip`, `stop` — подсказка, пропуск, завершение;
- `/cities` — «Города»;
- `/hangman` — «Виселица»;
- `/quiz` — викторина;
- `/whoami` — «Кто я?»;
- `/stopgame` — закончить текущую игру и вернуть обычное общение;
- `/rating` — вечный общий рейтинг;
- `/rating week` — рейтинг текущей недели;
- `/rating crocodile|cities|hangman|quiz|whoami` — рейтинг конкретной игры;
- `/mystats` — личная статистика, победы, серии и достижения;
- `/roast` — вручную подколоть человека ответом на его сообщение;
- `/ignore` — администратор отвечает этой командой на сообщение человека; Аксакал полностью перестаёт взаимодействовать с ним;
- `/unignore` — администратор отвечает на сообщение исключённого человека и возвращает его в общение;
- `/ignored` — список исключённых участников отправляется администратору в личный чат;
- `/good`, `/bad` — администратор оценивает AI-ответ;
- `/test` — диагностика Telegram и AI.

Административные slash-команды, отправленные в группе, автоматически удаляются после обработки, а результат и настройки отправляются администратору в личный чат с ботом. Для этого администратор должен хотя бы один раз открыть личный чат с ботом и нажать **Start**. Игровые действия остаются в группе, потому что их должны видеть участники.

Игры можно запускать и обычными фразами: **«давай играть»**, **«давай в крокодила»**, **«играть в города»**, **«давай викторину»**, **«давай в виселицу»**, **«давай сыграем кто я»**. Также понимаются **«покажи рейтинг»**, **«рейтинг недели»**, **«моя статистика»**, **«пропусти слово»** и **«закончи игру»**.

Короткие фразы **«помолчи»**, **«молчи»**, **«остановись»**, **«прекрати»**, **«подожди»**, **«хватит»**, **«отдохни»** переводят бота в ручной режим паузы. В ответ Аксакал пишет **«Ладно, дам чуть отдохнуть 😄»** и перестаёт отвечать сам или запускать оживление группы. Фразы **«Аксакал, где ты?»**, **«Аксакал, не молчи»**, частая опечатка **«акскал»**, @упоминание или Reply на сообщение бота автоматически снимают паузу; это же сообщение сразу проходит обычную обработку. Длинные фразы вроде «он сказал мне подожди» паузу не включают.

### Разговорная очистка сообщений

- **«удали мои сообщения»** — участник удаляет свои доступные сообщения, которые Аксакал успел получить;
- **«удали все твои сообщения»** / **«удали свои сообщения»** — только администратор удаляет доступные сообщения Аксакала;
- **«удали сообщения пользователя»** — только администратор, команду нужно отправить Reply на сообщение нужного участника;
- после успешного удаления записи убираются и из локального контекста Аксакала;
- Telegram Bot API разрешает удалять обычные сообщения только в пределах 48 часов, поэтому более старые сообщения бот удалить не сможет;
- все новые исходящие сообщения Аксакала централизованно сохраняют свои Telegram message ID, чтобы очистка работала не только для AI-реплик, но и для игровых и служебных сообщений.

### Профиль обращения

Если человек сам пишет **«я девушка» / «я парень»**, Аксакал сохраняет это как профиль обращения. Также можно ответить Reply на сообщение конкретного участника фразой **«это девушка»** или **«это парень»** — профиль сохранится именно ему. По имени, фотографии, username или стилю речи пол не определяется. Самоописание человека в дальнейшем может изменить сохранённый профиль.

Быстрые настройки вручную: `/hardness auto|normal|angry|super`; время ответа — `/time 0|3|5|20|40|60|180`; оживление молчащей группы — `/silence 15|30|60|180`.

В `/settings` время ответа выбирается кнопками: **Сразу (0 сек), 3 сек, 5 сек, 20 сек, 40 сек, 1 мин, 3 мин**. Там же есть вход в 🎮 игровой центр и 🏆 рейтинг.

Таймер самостоятельного оживления группы: **15 мин, 30 мин, 1 час или 3 часа**. Во время активной игры этот механизм не перебивает участников.

Режимы: **AUTO, Нормальный, Злой, Супер злой**. AUTO сам переключается по смыслу разговора.

## Игровая система

Игровой центр открывается фразой **«давай играть»** или командой `/games`. Доступны:

- 🐊 **Крокодил** — Аксакал объясняет слово; первый угадавший получает очко. Есть три уровня сложности, автоматические подсказки и кнопка пропуска слова;
- 🏙 **Города** — участник и Аксакал продолжают цепочку по последней подходящей букве. Поддерживаются `ё/е`, дефисы и небольшие опечатки; база содержит сотни городов;
- 🔤 **Виселица** — можно называть буквы или сразу слово, максимум шесть ошибок;
- ❓ **Викторина** — вопросы с четырьмя вариантами; ответ можно дать кнопкой, цифрой или текстом;
- 🎭 **Кто я?** — Аксакал даёт факты и дополнительные подсказки, участники угадывают человека или персонажа.

Обычная игровая сессия идёт **до 10 очков**. После десятого очка Аксакал объявляет победителя, показывает итоговый счёт и автоматически возвращается к обычному разговору. Если игра остановлена фразой **«закончи игру»** или кнопкой, режим игры также полностью завершается.

У раундов есть таймеры. В «Крокодиле» и «Кто я?» сначала приходит подсказка, затем ответ раскрывается и начинается новый раунд. В «Городах» Аксакал напоминает нужную букву, если группа долго молчит. В «Виселице» автоматически открывается буква, а в викторине после ожидания раскрывается ответ.

### Рейтинг и достижения

Статистика хранится в SQLite и не пропадает после перезапуска:

- вечный общий рейтинг и отдельный рейтинг каждой игры;
- недельный рейтинг;
- личная статистика через `/mystats`: очки, победы, сыгранные сессии, текущая и лучшая серия;
- достижения **«3 правильных подряд»**, **«10 побед в Крокодиле»**, **«50 городов»**;
- еженедельное достижение **«Король недели»** и автоматическое объявление лидера прошлой недели.

После перезапуска процесса активные игры и их таймеры восстанавливаются из базы.

## AUTO-режим

AUTO сам выбирает один из трёх характеров ответа:

- **Нормальный** — обычный разговор, вопросы, серьёзные темы, поддержка и уместные мудрые формулировки;
- **Злой** — спор, подколы, грубоватый тон, противоречия и слабые аргументы;
- **Супер злой** — очень жёсткий взрослый стёб, когда сам разговор уже идёт в таком ключе.

При реальной грусти или угрозах бот не должен усугублять ситуацию: он остаётся по теме, поддерживает или осаживает, но не разгоняет насилие.


## Эмоциональные режимы

- **Поддержка** — если чувствуется грусть, усталость, обида или тяжёлое настроение. Roast отключается.
- **Успокоение** — если разговор становится напряжённым или злым.
- **Суровый режим** — если появляется явная грубость; Аксакал осаживает поведение, но не разжигает конфликт.
- **Мудрый режим** — для серьёзных разговоров о жизни, отношениях, доверии, дружбе и решениях.
- **Шутливый режим** — обычные контекстные подколы, стикеры, реакции и молчуны.

## Когда Аксакал вмешивается

Аксакал не отвечает на каждое сообщение. Он ждёт подходящий момент: явный повод для подкола, смешную/дерзкую реплику, напряжение, грусть, серьёзную мысль, стикер или реакцию.

- На обычное сообщение ответ генерируется только по смыслу именно этого сообщения.
- Предыдущая переписка используется только как фон и память группы.
- Ответ отправляется через Telegram Reply без повторения имени человека в самом тексте.
- На стикер бот иногда отвечает отдельным подколом про то, что пора писать словами.
- После длительной тишины бот выбирает одного из знакомых участников и пытается расшевелить всю группу.


## AI-провайдеры

Текущая рабочая цепочка не использует Gemini, OpenRouter или прямой OpenAI API. Один ключ Groq даёт основную последовательность моделей:

1. `openai/gpt-oss-120b`;
2. `qwen/qwen3.8-27b`;
3. `openai/gpt-oss-20b`.

Если задан `MISTRAL_API_KEY`, после Groq используется независимый резерв `mistral-small-latest`.

`/test` делает реальный минимальный inference-запрос к каждой настроенной модели и показывает, какая из них действительно отвечает. Если одна модель получает rate limit или временную ошибку, бот ставит её на cooldown и пробует следующую.

## Память и защита от повторов

Аксакал:

- сохраняет собственные ответы в SQLite и видит их в следующем контексте;
- хранит историю сообщений группы;
- запоминает частые слова и реальные соседние фразы участников;
- ищет старые сообщения, связанные с текущей темой;
- получает список последних собственных ответов и меняет лексику и конструкцию;
- проверяет новый ответ на сильное сходство с недавними;
- при ошибке или плохом ответе одной модели переключается на следующую; готовых локальных фраз-ответов нет.

### AI-only ответы



Готовых ответов в коде больше нет. Каждый автоматический ответ должен быть сгенерирован одной из подключённых AI-моделей и пройти проверку на повторы, пересказ сообщения и шаблонные формулировки. Если ответ одной модели не проходит проверку, бот пробует следующую модель. Если все AI недоступны или все ответы плохие, бот молчит вместо бессмысленной заготовки.


## Ответы на вопросы

Аксакал — не только бот для шуток. Если последнее сообщение содержит настоящий вопрос, AI должен сначала дать полезный ответ по существу. Для вопроса ответ может быть длиннее обычной реплики и занимать несколько предложений. Шутка или местная подача добавляются только после содержательного ответа и только если это уместно.

Юмор строится на конкретной детали текущего разговора, противоречии, формулировке, реальной привычке участника или связанном callback из памяти группы. Натянутые универсальные подколы не должны заменять нормальный разговор.


## Понимание reply-цепочек и людей

Бот теперь сохраняет связи Telegram Reply. Если Магомед отвечает Али, а затем разговор продолжается ещё несколькими сообщениями, генератор получает именно эту ветку как отдельный приоритетный контекст, а не только последние сообщения группы подряд.

Для каждого участника автоматически строится безопасный поведенческий профиль только из переписки группы: сколько он пишет, как часто использует стикеры и реакции, повторяющиеся выражения, последние реплики и кому чаще отвечает. Этот профиль используется для более живых callback-шуток и понимания привычек, но не для догадок о здоровье, происхождении, религии или других чувствительных качествах.

## Разнообразие юмора

Аксакал хранит последние использованные приёмы юмора и старается не повторять один и тот же способ несколько раз подряд. Доступны сухая ирония, подкол логики, сравнение, гипербола, игра слов, callback к памяти группы и — в Супер злом режиме — уместная придирка к явной ошибке. Для серьёзного вопроса или поддержки юмор может быть полностью отключён.

## AI-редактор качества

После генерации локальные фильтры проверяют повтор, пересказ сообщения, имя в начале, шаблонность и утечку внутренних рассуждений. Если настроен Groq, хороший черновик дополнительно проходит короткую вторую AI-проверку: редактор либо подтверждает его, либо возвращает более естественную финальную реплику. Ошибка редактора не блокирует уже хороший основной ответ.


## Обучение по реакциям группы

Аксакал связывает каждый свой AI-ответ с использованным приёмом юмора. Реакции на его сообщение становятся обратной связью: 😂 🤣 🔥 ❤️ 👍 👏 💯 и похожие повышают вес приёма, а 👎 🤡 🙄 😒 💩 и похожие — понижают. Если реакцию убрать или заменить, запись обновляется, а не накручивается повторно.

Обычный Reply на сообщение Аксакала тоже считается сигналом вовлечения. Явные ответы вроде «бред», «не смешно», «неправильно», «скучно» снижают оценку; нормальное продолжение разговора даёт положительный сигнал, а явно одобрительная реакция — более сильный.

При выборе следующего типа юмора учитывается общая реакция группы и усиленный сигнал от ответов, которые раньше были адресованы конкретному участнику. Один случай не должен навсегда переучить бота: оценки сглаживаются, а недавно использованные приёмы всё равно временно исключаются из повтора.

В `/status` показывается количество накопленных сигналов обучения юмору.


## Ручное обучение администратора

Администратор может ответить командой `/good` или `/bad` прямо на AI-реплику Аксакала.

- `/good` даёт сильный положительный сигнал (+2);
- `/bad` даёт сильный отрицательный сигнал (-2);
- обычные участники этими командами переучивать бота не могут;
- повторная оценка того же ответа тем же администратором заменяет предыдущую, а не накручивает статистику.

Ручная оценка влияет не только на выбор типа юмора. Последние удачные и неудачные ответы передаются AI как примеры стиля: хорошие служат ориентиром по ритму и естественности, плохие показывают, каких конструкций избегать. Они не копируются дословно и не должны переносить старые факты в новую тему.


## Ответная грубость и более живая речь

Если участник обращается прямо к Аксакалу — через Reply, упоминание или по имени — и грубит ему, бот распознаёт это как отдельную ситуацию. В AUTO он отвечает жёстче и может вернуть сарказм, грубость или мат по конкретным словам собеседника вместо шаблонного «сбавь тон». Реальные угрозы и удары по чувствительным признакам при этом не используются.

Промпт также усилен на разговорную речь: меньше канцелярита, меньше обязательных моралей и «психологических» вступлений, больше естественного ритма, коротких фраз, встречных вопросов и нормального человеческого ответа по теме. Короткий хороший ответ теперь не отбрасывается только потому, что в нём меньше трёх слов.

## Надёжность AI-провайдеров

При HTTP 429 провайдер временно ставится на cooldown, а бот сразу пробует следующий настроенный AI. Это уменьшает повторные запросы в уже упёршийся в rate limit сервис.

Если основной ответ уже сгенерировал Groq, второй Groq-запрос на AI-редактуру теперь не делается. Это снижает расход бесплатного лимита примерно в тех случаях, где раньше на одну реплику уходило два Groq-запроса. Редактор также не должен «прилизывать» хороший разговорный ответ — он вмешивается только при явной проблеме.

## Оживление молчащей группы

Исправлен старый тупик, при котором после длительной тишины бот мог не найти кандидата, потому что всех недавно подкалывал и ждал до 6 часов. Теперь он предпочитает тех, кого не трогал последний час, но если таких нет — всё равно выбирает активного участника и пытается расшевелить группу.

В AUTO при таком самостоятельном выходе бот сам варьирует тон: иногда мягко зовёт человека в разговор, чаще делает средний подкол, иногда выбирает жёсткий вариант. Он старается использовать реальные привычки, локальную память и разные приёмы юмора, а не каждый раз писать одну и ту же фразу про тишину.

## Чистые команды в Telegram

В группах Telegram-меню slash-команд теперь скрыто. После выполнения пользовательская команда (/settings, /status, /good, /bad, /time и т. п.) удаляется из чата, если у бота есть право удалять сообщения. Короткие служебные ответы на команды также автоматически исчезают примерно через 12 секунд. Сам AI-ответ, обычная беседа и результат /roast остаются в чате.

Панель /settings остаётся видимой, потому что это интерактивное меню с кнопками. Чтобы команды действительно удалялись в группе, бот должен быть администратором с правом удаления сообщений.

В личном диалоге Telegram-меню содержит только реально работающие там команды: /start, /help, /test. Групповые настройки специально не показываются в личном меню.

## Дополнительный AI: Google Gemini

В резервную цепочку добавлен независимый Google Gemini. По умолчанию используется стабильная модель gemini-3.5-flash-lite.

Добавьте на сервере:

```env
GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.5-flash-lite
```

При наличии ключей порядок генерации теперь: OpenAI → Groq/Qwen → Gemini → OpenRouter/Qwen/DeepSeek. Если один сервис временно недоступен или упирается в лимит, Аксакал продолжает со следующим.
